# Microsoft Store Screenshot Placeholders

PWABuilder and Partner Center should receive real PNG screenshots before submission. Capture them from the installed PWA or live app window after signing in with the reviewer demo account.

Recommended set:
- Desktop wide: 1366 x 768 or larger 16:9 screenshot of signed-in Home/dashboard.
- Desktop wide: question submission screen.
- Desktop wide: education/article screen.
- Desktop wide: questions/history screen with demo-safe content.
- Mobile/narrow optional: settings/ad preferences.

Do not upload splash-screen-only or login-screen-only images. Do not upload screenshots that show real patient data, private questions, phone numbers, or email addresses.
