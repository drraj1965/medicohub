# Microsoft Store Submission Checklist

## App Identity

- App name: MedicoHub Connect
- Short name: MedicoHub
- Package path: PWA first through PWABuilder
- Category recommendation: Medical or Health & Fitness; Education can be secondary in description/keywords
- Age rating: likely suitable for general audiences, but disclose medical education and user-generated content/moderation

## Store Listing

- Short description: Educational doctor-patient communication, community questions, and health learning support.
- Long description: Emphasize non-emergency educational communication, question threads, education library, and vestibular exercise guidance.
- Keywords: doctor patient education, health questions, neurology education, rehabilitation, second opinion, patient communication
- Privacy policy URL: `https://mediconverse.web.app/privacy.html`
- Support URL: `https://mediconverse.web.app/support.html`
- Website URL: `https://mediconverse.web.app/`

## Required Screenshots

- Capture screenshots from the installed PWA or live app window after signing in with the reviewer demo account.
- Home/dashboard screen showing actual app navigation and signed-in state.
- Ask Question page with demo-safe text.
- Questions/history page with demo-safe threads.
- Education/article page.
- Settings/ad preferences page if ads are enabled.

Do not submit splash-screen-only or login-screen-only images. Do not show real patient data, private phone numbers, or private emails.

## Icons

- 192 x 192 PNG.
- 512 x 512 PNG.
- Maskable icons.
- Square Store logo assets may be generated by PWABuilder.

## Certification Checklist

- App starts from Store package.
- Demo account works.
- Backend is awake and reachable.
- Privacy policy opens.
- Support URL opens.
- Medical disclaimer is visible.
- Account deletion instructions are available.
- Ads are labeled.
- No ads in private questions/messages.
- Offline behavior shows a friendly message.

## Testing Checklist

- Build web: `flutter build web --release`
- Open `build/web/index.html` through a local server.
- Run PWABuilder check.
- Test install window.
- Test login.
- Test article reading and YouTube playback.
- Test question submission.
- Test offline fallback by disabling network after first load.
