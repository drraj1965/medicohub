# Growth Studio Admin Guide

Open MedicoHub, sign in as an authorised admin, and use the drawer item `Growth Studio`.

Tabs:

- Overview: acquisition, activation, retention, sharing, referral, and sample-size metrics.
- Campaigns: create measurable campaigns with audience, CTA, primary metric, and channel plan.
- Opportunities: review generated demand from public MedicoHub questions and stored opportunities.
- Promotion: create traceable promotional derivatives from published articles.

No external social publishing occurs from this module yet.
